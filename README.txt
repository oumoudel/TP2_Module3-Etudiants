PROJET TP MODULE 3 — LISTE DES ÉTUDIANTS

Contenu du dossier
- etudiants.xml : données XML de la promotion.
- liste.xsl : transformation en liste HTML (étape 3).
- tableau.xsl : page HTML avec statistiques, tableaux par classe, tri, rang, moyenne et résultat (étapes 4 à 9).
- style.css : mise en forme personnalisée.
- reponses-tp3e.txt : réponses aux questions écrites.

Pour utiliser le projet
1. Décompressez le ZIP.
2. Ouvrez le dossier tp2-module3-etudiants dans VS Code.
3. Remplacez le commentaire de chaque feuille XSL par votre matricule et vos nom/prénom.
4. Les feuilles XSLT sont à remettre à l'enseignant selon les consignes du TP. Le sujet précise que l'enseignant exécute les feuilles en séance.
5. La page HTML générée doit être placée dans le même dossier que style.css, puis ouverte dans un navigateur.

Remarque
Le fichier tableau.xsl est une version finale évoluée correspondant aux étapes 4 à 9. La feuille liste.xsl correspond à l'étape 3.
